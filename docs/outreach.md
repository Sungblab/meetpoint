# 첫 주최자 3곳 찾기

작성일: 2026-09-29 · 담당: 김성빈

## 목표

- **10월 안에 실제 행사 3곳에서 Meetpoint를 쓴다.** 정기적으로 여는 주최자를 우선한다.
- 행사가 끝나면 볼 숫자는 세 가지다.
  1. 입장률: 실제 참석자 중 Meetpoint에 들어온 비율
  2. 1인당 연결 수: 서로 연결된 수 × 2 ÷ 참가자
  3. **주최자가 다음 행사에도 쓰겠다고 하는가.** 가장 중요하다.

## 먼저 알아둘 규칙

이걸 어기면 과태료나 처벌 대상이 된다.

- **이메일 주소를 프로그램으로 모으지 않는다.** 웹페이지에서 이메일을 자동으로 수집하는 것 자체가 불법이다(정보통신망법 50조의2). 목록은 손으로 만든다.
- **여러 곳에 같은 메일을 한꺼번에 보내지 않는다.** 동의 없이 광고 메일을 보내면 안 된다(정보통신망법 50조). 주최측이 **제휴·협업·문의 창구로 공개한 곳**에 행사별로 따로 쓴 제안을 한 곳씩 보낸다.
- 공개된 문의 창구가 없는 곳은 메일을 보내지 않는다. 현장에서 직접 말을 걸거나 아는 사람에게 소개를 받는다.
- 답이 없으면 딱 한 번만 다시 묻는다. 거절하거나 원하지 않는다고 하면 목록에 표시하고 다시 연락하지 않는다.

## Task 0. 연락하기 전 준비 (하루)

- [ ] `admin` 브랜치를 배포한다. 서버 `.env`에 `ADMIN_PASSWORD`, `SMTP_HOST=smtp.gmail.com`, `SMTP_USER`, `SMTP_PASSWORD`(Gmail 앱 비밀번호)를 넣는다.
- [ ] 내 이메일로 방을 하나 만들어 관리 주소 메일이 오는지 확인한다.
- [ ] 데모 방을 하나 만들고, 합성 참가자 5명 정도를 넣어 둔다. 제안할 때 "직접 해보기" 링크로 쓴다.
- [ ] `/admin`에 들어가서 데모 방의 참가자와 연결 수가 보이는지 확인한다.
- [ ] 보내는 사람 이름과 연락처(메일, 원하면 전화번호)를 정한다.

## Task 1. 행사 찾기 (목표 25곳, 이틀)

**찾을 곳**
- 이벤터스, 온오프믹스, Luma: "네트워킹", "밋업", "창업", "AI", "스타트업"으로 검색한다.
- K-Startup(창업진흥원)의 행사·교육 공지, 지역 창업센터, 대학 창업지원단 공지
- 개발 행사 모음(GitHub의 Dev-Event 목록), 링크드인 이벤트
- 개발자·창업 커뮤니티의 정기 모임 공지

**고르는 기준** (모두 맞으면 A, 둘 이상 맞으면 B)
- 오프라인이고 참가자가 20~80명
- 강연이나 발표 뒤에 네트워킹 시간이 있다고 적혀 있다
- 정기적으로 연다 (매달, 분기마다, 시리즈의 N회차)
- 창업·IT·AI 주제
- 행사일이 2~6주 뒤다 (제안하고 준비할 시간이 있다)

**할 일**
- [ ] 아래 표 형식으로 25곳을 적는다. 문의 창구는 페이지에 공개된 것만 적는다.
- [ ] A, B, C로 나누고 A부터 연락한다.

| # | 행사명 | 날짜 | 장소 | 예상 인원 | 주최 | 정기 여부 | 네트워킹 시간 | 공개 문의 창구 | 링크 | 등급 | 상태 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | | | | 조사 |

상태는 `조사 → 보냄 → 다시 물음 → 답장 → 확정 → 진행 → 결과 공유 → 재사용` 순서로 바꾼다. 거절하면 `거절`로 적는다.

## Task 2. 제안 보내기 (하루 5곳 이하)

- [ ] A등급부터 한 곳씩 보낸다. 행사명과 그 행사에 맞는 한 줄은 반드시 고쳐 쓴다.
- [ ] 보낸 날짜와 채널을 표에 적는다.
- [ ] 5영업일 안에 답이 없으면 짧게 한 번 더 묻는다. 그 뒤에는 멈춘다.

**메일·문의 창구용 템플릿**

```
제목: {행사명} 네트워킹 시간에 무료로 써보실 도구를 제안드려요

안녕하세요, {담당자}님. {행사명} 공지를 보고 연락드려요.
행사 네트워킹 도구 Meetpoint를 만든 김성빈입니다.

{이 행사에 맞는 한 줄. 예: 강연 뒤 30분 네트워킹이 있다고 봤어요.}

참가자가 QR로 들어와 2분 동안 자기소개를 적으면, AI가 먼저 만나면 좋을 사람과 첫마디를 추천해 줘요.
추천은 두 가지예요. 같은 분야에서 먼저 해본 사람, 그리고 내가 못 하는 걸 도와줄 다른 분야 사람.
앱 설치나 회원가입은 없고, 서로 '만나고 싶어요'를 누른 사람끼리만 연락처가 열려요.

다음 {행사명}에서 무료로 한 번 써보시면 어떨까요?
방은 1분이면 만들 수 있고, 원하시면 당일 현장에서 제가 도와드릴게요.
끝나면 참가자 수와 서로 연결된 수를 정리해서 보내드릴게요.

- 소개 영상과 서비스: {Meetpoint 주소}
- 직접 해보기: {데모 방 주소}

관심 없으시면 답장 한 줄만 주세요. 다시 연락드리지 않을게요.

김성빈 드림 · {연락처}
```

**다시 물을 때**

```
제목: Re: {행사명} 네트워킹 도구 제안

{담당자}님, 지난주에 보낸 제안 한 번만 다시 여쭤요.
{행사 날짜} 행사에 무료로 써보실 생각이 있으시면 편하게 답장 주세요.
아니시면 여기서 멈출게요. 감사합니다.
```

**현장에서 말로 할 때 (30초)**

> 오늘 네트워킹 시간 보니까 다들 누구한테 말 걸지 고민하시더라고요. 제가 이걸 도와주는 도구를 만들었어요. QR 찍고 2분 적으면 먼저 만나면 좋을 사람과 첫마디를 추천해 줘요. 다음 행사에서 무료로 한 번 써보실래요? 제가 당일 와서 도와드릴게요.

## Task 3. 확정되면 (행사 1주 전)

- [ ] 주최자와 확인한다: 날짜, 예상 인원, 네트워킹 시간 길이, 프로젝터 유무, 현장 와이파이
- [ ] 방은 주최자가 자기 이메일로 만들게 안내한다. 운영자 화면의 주최자별 기록이 여기에 달려 있다.
- [ ] 주최자에게 안내 문구를 드린다: "강연 끝나면 화면의 QR을 찍어 주세요. 2분이면 돼요."
- [ ] 전날 휴대폰 두세 대로 입장, 추천, 서로 연결까지 끝까지 해본다.
